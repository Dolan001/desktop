# Production delivery

Preserve security boundaries by launching processes with argument arrays, validating repository
URLs, and keeping credentials out of files and logs. Keep the Qt event loop responsive and expose
errors through recoverable UI states. Tests must cover real behavior rather than static source
claims. Build and install the Python package after changes that affect entry points or resources;
platform-specific native packaging requires evidence from that operating system.
Independent verification must repeat the applicable tests from the installed artifact.
